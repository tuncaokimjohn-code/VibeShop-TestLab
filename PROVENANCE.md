## Implementation decisions

The two trees share comparable application, API, authentication, data, configuration, type and UI modules.
Route descriptors expose HTTP method/path relationships for analysis without starting a transport.
Database and session-verification ports are interfaces, and host secret lookup is an abstraction.
No live adapters, listener, payment code, email service, production login provider or deployment configuration exists.
The storefront is deliberately simple and receives data through props.
Fictional JSON records include two customers, a catalog manager, products, orders and plain-text reviews.
Case-specific assertions, line evidence and expected findings are maintained outside the project root.
The fixture does not implement a scanner or contain importer-specific instructions.
